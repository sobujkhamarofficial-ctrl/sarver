# Halal Food Website

A responsive starter website for Halal Food, a Bangladeshi halal food and grocery brand.

## Features
- Responsive layout for mobile and desktop
- Product showcase cards
- Navigation and contact section
- Plain HTML, CSS, and JavaScript; no build step required

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages** and select the `main` branch and `/ (root)` as the source. Save to publish.

This is a starter project. Replace demo product details and contact information with verified business information before launch.
